# Mirror Match: art

**Status:** none yet. Until an image exists, the game shows a stand-in (a drawn Mira, or a brand-kit badge). Drop a file in with the exact name below and the game uses it automatically. No code changes needed.

Use the brand prompt from itsdrdan.github.io/games/brand and change only the Subject line. Glossy cartoon style, transparent background, no text.

Structures, wedges, Fischer projections and the cis/trans drawings inside questions are drawn by the game's code on purpose (the bonds and atoms must be exact). Don't make those.

**25 images total: 1 logo + 5 menu badges + 11 achievement badges + 2 feature badges + 5 mascot moods (+ 1 study hub card copy of the logo).**

## The mascot: Mira the mirror (5 moods)

Mira is a cute oval hand mirror with a soft lavender frame and a short handle, a pale blue reflective glass face, rosy cheeks and big friendly eyes. In her glass, faintly, is the reflection of a small left hand (her trademark: mirror images). Make all five on one sheet so she looks identical in each. Cut each to **320 × 320 transparent WebP**.
